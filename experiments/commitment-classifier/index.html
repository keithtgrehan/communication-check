How this experiment works

TF-IDF word features and logistic regression learn weights from labelled examples. The model does not generate text. A threshold was selected using a separate development set before an independent synthetic test.

The model forces a classification for valid input, including ambiguous or unfamiliar wording. “No firm delivery classification” is not an all-clear. It does not review pricing, general capabilities or other communication issues.

After the page and model load, classification runs in browser memory with no text submission or storage. Reloading clears the passage. Synthetic performance does not establish real-world accuracy or usefulness.
